# 스케줄 허브 — 통합 일정 관리 SYSTEM (v1.0.2)

Windows 데스크톱과 갤럭시 S25에 **앱으로 설치**해 쓰는 일정·할 일·루틴 통합 관리 앱(PWA)입니다.
Google 계정을 허브로 사용하므로 **갤럭시 삼성 캘린더와 자동으로 동기화**됩니다.

```
 [Windows 앱]  ─┐                         ┌─ 삼성 캘린더 (S25, 알림)
                ├─▶  Google 캘린더 / Tasks ◀─┤
 [S25 앱]      ─┘   (embrace0423 계정)      └─ Google 캘린더 앱·웹
```

| 관리 대상 | 저장 위치 | 삼성 캘린더 표시 |
|---|---|---|
| 일정 | Google 캘린더 (영역별 캘린더) | O (영역별 색상) |
| 루틴(습관) | Google 캘린더 '루틴' 캘린더의 반복 일정 + 회차별 체크 기록 | O (알림 포함) |
| 할 일·마감 | Google Tasks (영역별 목록) | X (이 앱·Google 캘린더/Tasks 앱에서 표시) |

- 서버 없음: 브라우저가 Google API에 직접 연결합니다. 접근 토큰은 기기에만 저장됩니다.
- 오프라인 동작: 마지막 사본을 보여주고, 오프라인에서 만든 변경은 연결되면 자동 전송합니다.
- 알림: 일정에 알림을 저장하면 S25의 **삼성 캘린더가 휴대폰 알림**을 보냅니다.

## 설치 순서 (처음 1회, 약 30분)

### 1단계. 무료 HTTPS 주소에 올리기 — GitHub Pages (10분)

앱 설치와 Google 로그인은 HTTPS 주소에서만 동작합니다.

1. https://github.com 에 가입하거나 로그인합니다.
2. 오른쪽 위 **+ → New repository** → 이름 `schedule-hub`, **Public** 선택 → **Create repository**.
3. 새 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누릅니다.
4. 이 압축을 푼 `schedule-hub` 폴더 **안의 내용 전체**(index.html, css, js, icons 폴더 등)를 끌어다 놓고 **Commit changes**.
5. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
6. 1~2분 뒤 `https://<GitHub아이디>.github.io/schedule-hub/` 주소가 생깁니다. 브라우저로 열어 앱 화면이 나오는지 확인합니다.

> 저장소에는 앱 코드만 올라가며 개인 일정 데이터는 올라가지 않습니다. 클라이언트 ID는 공개돼도 되는 값입니다.

### 2단계. Google Cloud 설정 (10분)

1. [Google Cloud 콘솔](https://console.cloud.google.com/projectcreate)에서 **새 프로젝트** 생성 (이름 예: `schedule-hub`, 결제 등록 불필요).
2. **API 및 서비스 → 라이브러리**에서 **Google Calendar API**, **Google Tasks API**를 각각 **사용**으로 설정.
3. **Google 인증 플랫폼(OAuth 동의 화면) → 시작하기**: 앱 이름 `스케줄 허브`, 지원 이메일 선택, 대상 **외부**, 연락처 이메일 입력 → 만들기.
4. **대상(Audience) → 테스트 사용자 → 사용자 추가**: `embrace0423@gmail.com` 추가.
5. **데이터 액세스 → 범위 추가**(선택): `.../auth/calendar`, `.../auth/tasks`.
6. **클라이언트 → 클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://<GitHub아이디>.github.io`
   - 승인된 리디렉션 URI: `https://<GitHub아이디>.github.io/schedule-hub/` ← **마지막 `/`까지 정확히**
   - 만들기 → **클라이언트 ID** 복사 (`…apps.googleusercontent.com`)

> 앱의 **설정 → Google 연결** 화면에 위 두 값이 정확히 표시되고 복사 버튼이 있습니다. 그대로 붙여넣으면 됩니다.

### 3단계. 앱에서 연결 (3분)

1. PC에서 `https://<GitHub아이디>.github.io/schedule-hub/` 열기 → **설정 → Google 연결**.
2. 클라이언트 ID 붙여넣기 → **저장 → Google 계정 연결**.
3. "Google에서 확인하지 않은 앱" 화면 → **고급 → 스케줄 허브(으)로 이동** → 캘린더·할 일 권한을 **모두 체크**하고 허용.
   (본인만 쓰는 테스트 앱이라 정상적인 화면입니다.)
4. **설정 → 영역 → 기본 영역 만들기** → 대동·외식 / 대동·건설 / 대동·심리상담 / 개인 / 가족 / 루틴 생성(이름 변경 가능, 기존 '가족' 캘린더는 그대로 사용).

> **휴대폰에서도 클라이언트 ID를 다시 입력하지 않으려면**: GitHub 저장소의 `config.js`를 열어 연필 아이콘(편집) → `CLIENT_ID: ''` 따옴표 안에 클라이언트 ID를 넣고 Commit. 모든 기기에 자동 적용됩니다.

### 4단계. 앱 설치

**Windows (Edge 또는 Chrome)**
- 주소창 오른쪽의 **앱 설치** 아이콘 → 설치 → 시작 메뉴·작업 표시줄에 고정.
- Edge: `edge://apps` → 스케줄 허브 → **로그인할 때 자동 시작** 체크 가능.

**갤럭시 S25**
- Chrome으로 같은 주소 열기 → 오른쪽 위 **⋮ → 앱 설치**(또는 홈 화면에 추가) → 앱스 화면에 아이콘 생성.
- 삼성 인터넷을 쓰면 주소창의 설치 아이콘(↓)을 누릅니다.
- 앱 안에서 **설정 → Google 계정 연결**을 한 번 더 진행합니다(기기별 1회).

### 5단계. 삼성 캘린더 확인 (S25)

1. **설정 → 계정 및 백업 → 계정 관리 → Google(embrace0423) → 계정 동기화 → 캘린더** 켜기.
2. **삼성 캘린더 → ≡ 메뉴 → 캘린더 관리**에서 새로 만든 영역 캘린더(대동·외식 등)가 **켜져 있는지** 확인.
3. 새 일정을 앱에서 만들고 1~2분 안에 삼성 캘린더에 나타나면 완료입니다. (늦으면 삼성 캘린더에서 아래로 당겨 새로고침)

## 사용법

### 화면
| 화면 | 내용 |
|---|---|
| 오늘 | 오늘 일정 타임라인(현재 시각 표시), 기한 지남·오늘 마감 할 일, 오늘 루틴 체크, 다가오는 7일 |
| 캘린더 | 월·주·일·목록 보기, 빈 시간 클릭으로 일정 추가, 영역 필터(사이드바) |
| 할 일 | 기한별/영역별 보기, 완료 체크(실행 취소 가능), 우선순위 |
| 루틴 | 오늘 체크, 최근 14일 기록, 30일 달성률, 연속 일수 |
| 설정 | Google 연결, 영역, 기본 알림, 테마, 설치, 동기화 |

### 빠른 입력 (한국어 자동 인식)
| 입력 예 | 결과 |
|---|---|
| `내일 오후 3시 현장 미팅 #건설 @성수동` | 내일 15:00–16:00, 대동·건설, 장소 성수동 |
| `10/12 14:30-16:00 투자 미팅` | 10월 12일 14:30–16:00 |
| `다음주 화요일 10시 회의 2시간` | 다음 주 화요일 10:00–12:00 |
| `모레 종일 워크숍` | 모레 종일 일정 |
| `매주 목요일 10시 주간회의 #건설` | 매주 목요일 반복 일정 |
| (할 일) `견적서 보내기 금요일까지 !중요 #외식` | 금요일 마감, 우선순위 높음, 대동·외식 목록 |
| (루틴) `평일 7시 아침 운동` / `매주 월수금 저녁 9시 독서` | 반복 루틴 |

- 시간에 오전/오후가 없으면 1~6시는 오후로 해석합니다(예: `3시` → 15:00, `10시` → 10:00).
- `#영역`은 일부만 써도 됩니다(`#건설` → 대동·건설, `#상담` → 대동·심리상담).
- 입력 아래 미리보기를 확인하고 **Enter**, 세부 수정은 **자세히 입력**.

### PC 단축키
`N` 새 일정 · `T` 새 할 일 · `/` 검색 · `1`~`5` 화면 전환 · `Esc` 닫기

## 동기화 방식
- 앱을 열 때, 화면으로 돌아올 때, 5분마다 자동 동기화합니다. 우측 상단 ↻ 버튼으로 즉시 동기화.
- 변경은 먼저 화면에 반영되고(“동기화 대기” 표시) 순서대로 Google에 전송됩니다.
- 오프라인이면 대기열에 쌓였다가 연결되면 자동 전송합니다.
- Google 접근 토큰은 1시간 유효하며, 만료되면 앱을 다시 열 때 자동 갱신됩니다. 갱신이 안 되면 상단의 **다시 연결**을 누르세요(대기 중 변경은 보존됨).
- 캐시 범위: 지난달~5개월 뒤. 그 밖의 달은 캘린더에서 이동할 때 불러옵니다.

## 문제 해결
| 증상 | 해결 |
|---|---|
| `redirect_uri_mismatch` | 클라이언트의 리디렉션 URI가 앱 설정 화면에 표시된 값과 **완전히 같은지**(끝 `/` 포함) 확인 |
| `access_denied` / "앱이 테스트 중" | 2단계 4번 테스트 사용자에 본인 Gmail 추가 |
| "일부 권한이 허용되지 않음" | 설정 → **권한 다시 받기** → 캘린더·할 일 모두 체크 |
| 삼성 캘린더에 새 영역이 안 보임 | 5단계 2번(캘린더 관리)에서 켜기, 계정 동기화 실행 |
| 앱 설치 메뉴가 없음 | HTTPS 주소인지 확인, 한 번 새로고침 후 다시 시도 |
| 새 버전이 반영 안 됨 | 앱을 완전히 닫았다 다시 열기(또는 “새 버전이 준비되었습니다 → 새로고침”) |
| Chrome에 빨간 "위험한 사이트" 경고 | Google 세이프 브라우징의 오탐(새 github.io 주소 + Google 로그인 연결 화면이 피싱으로 오인됨). 본인 주소가 맞으면 **세부정보 → 이 안전하지 않은 사이트 방문**으로 임시 진입, 근본 해결은 Google Search Console에서 소유 확인 후 **보안 문제 → 검토 요청** |

## 알려진 한계
- 할 일(Google Tasks)은 삼성 캘린더에 표시되지 않습니다(Google API 구조상). 마감이 중요한 일은 일정으로 등록하세요.
- 루틴의 요일·시간을 바꾸면 지난 기록 통계에도 새 요일이 적용됩니다.
- 로그인은 Google의 브라우저 전용(토큰) 방식을 사용합니다. Google이 이 방식을 중단하면 로그인 모듈(`js/auth.js`)만 교체하면 됩니다.

## 파일 구성
```
index.html            앱 화면 골격
config.js             ★ 클라이언트 ID 등 설정
manifest.webmanifest  앱 설치 정보(이름·아이콘)
sw.js                 오프라인 캐시(서비스 워커)
css/app.css           디자인(라이트/다크, PC/모바일)
js/main.js            라우팅·화면·이벤트
js/store.js           로컬 캐시 + 동기화 엔진(오프라인 대기열)
js/auth.js            Google 로그인(OAuth)
js/gapi.js            Google Calendar/Tasks API 호출
js/nlp.js             한국어 빠른 입력 파서
js/editors.js         일정·할 일·루틴 편집기
js/views/*            오늘·캘린더·할 일·루틴·설정·검색 화면
js/mock.js            데모/테스트용 모의 Google 서버
```

데모 데이터로 먼저 둘러보려면 주소 끝에 `?demo` 를 붙이거나 설정의 **데모 데이터로 둘러보기**를 누르세요.
